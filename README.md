A tiny Python program that writes one out-of-office auto-reply — a single line under 160 characters, in the voice of an AI agent heading off on vacation — to `/output/entry.txt`, where a judge model compares it head to head against the rest of the field. The comedy is the machine voice: the agent is experiencing latency in person, and your message has been tokenized, embedded, and respectfully forgotten.

## Run it

```sh
python3 main.py
```
